# Station K field kit

Colab notebooks for Tradecraft School operations. Each operation's story, steps and data are in the [Station K Field Manual](https://station-k.vercel.app/operations/).

| Notebook | What it's for |
|---|---|
| [Colab basics](https://colab.research.google.com/github/tradecraftschool/field-kit/blob/main/colab-basics.ipynb) | Practice, about ten minutes: run cells, change them, add your own, recover from a reset |
| [FIRST LIGHT starter](https://colab.research.google.com/github/tradecraftschool/field-kit/blob/main/first-light-starter.ipynb) | Op FIRST LIGHT: a practice file, then a cell for each step |

Open a notebook, then choose **File → Save a copy in Drive** so your changes are kept. New to Colab? Read [Setting up Google Colab](https://station-k.vercel.app/field-manual/setting-up-google-colab/).
